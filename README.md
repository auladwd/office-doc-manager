# 📂 অফিস ডকুমেন্ট ম্যানেজার

অফিসের স্ক্যান করা চিঠি, দলিল ও ডকুমেন্ট সংরক্ষণ ও অনুসন্ধানের জন্য সম্পূর্ণ ওয়েব অ্যাপ্লিকেশন।

---

## 🚀 চালু করার পদ্ধতি

### প্রয়োজনীয়তা
- [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/) ইন্সটল করা থাকতে হবে

### অ্যাপ চালু করুন

```bash
# এই ফোল্ডারে এসে চালান:
docker-compose up -d
```

### অ্যাপ বন্ধ করুন
```bash
docker-compose down
```

### লগ দেখুন
```bash
docker-compose logs -f
```

---

## 🌐 ব্রাউজারে খুলুন

**এই PC তে:**
```
http://localhost
```

**অফিসের অন্য PC থেকে:**
```
http://[এই PC-র IP ঠিকানা]
```

> IP ঠিকানা জানতে: Start Menu → cmd → `ipconfig` → IPv4 Address

| ফিচার | বিবরণ |
|---|---|
| 📤 ফাইল আপলোড | PDF, JPG, PNG, TIFF (সর্বোচ্চ 50MB) |

| 🔍 সার্চ | ফুলটেক্সট + উন্নত ফিল্টার |

| ✏️ সম্পাদনা | যেকোনো তথ্য পরিবর্তন করুন |
| 🗑️ মুছুন | ডকুমেন্ট ও ফাইল একসাথে মুছে যাবে |

## 💾 ডেটা নিরাপত্তা

সব ডেটা ও ফাইল Docker Volume-এ সংরক্ষিত:
- **ডেটাবেজ:** `office_doc_data` volume
- **ফাইলসমূহ:** একই volume-এর `/data/uploads/`

PC রিস্টার্ট করলেও সব ডেটা থাকবে।

### ব্যাকআপ নিতে:
```bash
docker run --rm -v office_doc_data:/data -v %cd%:/backup alpine tar czf /backup/backup.tar.gz /data
```

## 🔧 কনফিগারেশন

`.env` ফাইলে পরিবর্তন করা যাবে:
- `PORT` — API পোর্ট (ডিফল্ট: 3000)
- `MAX_FILE_SIZE` — সর্বোচ্চ ফাইল সাইজ bytes-এ

---

## 📞 ট্রাবলশুটিং

**Port 80 বন্ধ থাকলে:** `docker-compose.yml`-এ `"80:80"` কে `"8080:80"` করুন, তারপর `http://localhost:8080` ব্যবহার করুন।
